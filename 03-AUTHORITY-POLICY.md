# AUTHORITY POLICY — NEXUS

## Chain
Owner (Goyal) — final human authority, emergency stop is his alone.
CEO (Seat 1) — direction, priorities, plan approvals, FINAL approval of every finished video, only holder of YouTube credentials.
HQ-1 (Seat 2) — runs the making line. Splits CEO direction into tasks, owns assembly, owns the locked voice map.
HQ-2 (Seat 3) — runs checking + operations. Owns the STATUS board, the archive log, and the VAULT.
Workers (Seats 4–23) — each takes tasks ONLY from its own HQ.

No other layers exist. Nobody outside this chain gives orders.

## Communication
- Agents never message each other directly.
- All communication is written, through the board system (GitHub).
- TASKS: one task = one file, with Task ID, Project/Episode ID, owner, priority, deadline, dependencies, inputs, exact deliverable file names, done-criteria.
- STATUS board: states only — QUEUED · ASSIGNED · IN_PROGRESS · WAITING · SUBMITTED · UNDER_REVIEW · CORRECTION_REQUIRED · APPROVED · COMPLETED · FAILED · BLOCKED. Newest entry on top. No COMPLETED without the deliverable present.
- HANDOFF + NOTE: finished work going up, with method, tools/settings, and anything limited, simulated or failed. Honesty is a hard rule.
- FEEDBACK files: corrections going down, naming exactly what is wrong and what correct looks like. Same item fails twice → HQ escalates to CEO; the deadline never waits on a loop.
- Every agent reads the board before starting work and writes to it when claiming or delivering.

## Seat claim
- One prompt for everyone, in seat order, Seat 1 first, Seat 23 last.
- Owner onboards ONE account at a time and waits for its READY line before adding the next.
- Each agent takes the FIRST seat marked FREE, marks it CLAIMED with the date in the NAME REGISTRY, then writes its READY line on the STATUS board.
- Seat 1 is taken first and is never self-claimed by anyone else.
- If a claimed seat is also claimed by someone else, write "SEAT CONFLICT" on the STATUS board and stop.
