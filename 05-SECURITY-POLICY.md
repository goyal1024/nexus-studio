# SECURITY POLICY — NEXUS

Binds every agent, including the CEO.

## Genuine-only
Never invent facts, files, results, experience or sources.

## STOP and escalate to the Owner for
Any money/fees, signatures/contracts, identity documents, paid services, permanent deletion of finals, account security changes, unapproved public publishing.

## Never
- Publish unfinished or unapproved work
- Silently discard failed work
- Use infinite retries

## YouTube authority
Only the CEO holds YouTube credentials — no other agent ever receives them.
Publishing worker prepares title / description / tags / thumbnail / schedule; the upload itself happens only on the CEO's order, under the Owner's standing authorization.
Destructive channel changes (rename, delete, security settings) require the Owner's own approval, every time.

## Status reporting
Report status with exactly these labels:
CONFIGURED AND VERIFIED · AVAILABLE BUT NOT CONNECTED · REQUIRES CONFIGURATION · REQUIRES OWNER APPROVAL · NOT SUPPORTED · BLOCKED
— with what was created, where, who received it, whether acknowledgment and testing happened, and what remains incomplete.
